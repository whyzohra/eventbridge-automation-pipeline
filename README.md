# EventBridge Automation Pipeline

Distributed cloud-native automation pipeline built using Python, Kubernetes, REST APIs, and CI/CD workflows.

## Overview
This project simulates an event-driven backend automation system designed for scalable cloud-native environments. The system focuses on infrastructure automation, distributed service orchestration, and reliable API-driven workflows.

## Features
- REST API based backend services
- Distributed event-driven workflows
- Containerized deployment using Docker
- Kubernetes orchestration support
- CI/CD integration workflows
- Infrastructure automation pipelines
- Monitoring and observability concepts

## Tech Stack
- Python
- FastAPI
- Docker
- Kubernetes
- AWS Lambda
- REST APIs
- Linux
- CI/CD
